How updates work

  • This page updates itself. When a release is published, edited or removed on GitHub, it moves from Coming up to Recently released within a couple of minutes.
  • Updates come in cycles. A Major update (like 1.5) starts a cycle. It is followed by five Minor updates, and then the next Major (1.6).
  • A Minor update is small and has one theme. The fifth Minor of every cycle is a Stability update: no new features, just fixes, speed, safety checks and tidying up.
  • A Hotfix is an urgent fix for something serious, like anything that could lose your data. It doesn't wait its turn and it doesn't count toward the five.
  • Every update carries a tag shown beside its version number: MAJOR, MINOR, STABILITY or HOTFIX. An update can also carry a BETA tag while it is being tried out. A beta is published as a pre-release that the automatic updater skips, so only people who choose to download it get it. A tag is a separate label, so the version number never changes, and when a beta is ready the BETA tag simply comes off. Betas apply to the downloads (desktop installers and the browser zip); the website only ever shows a finished version.
  • A single feature can carry a BETA tag too, shown beside it in the list. It still comes in a finished update that everyone gets, but it is newer and less proven, so it may change, or be switched off if it causes trouble. When it has proved itself the tag comes off.
  • Version numbers only go up, so a Hotfix in the middle of a cycle moves the numbers after it up by one. The tags always say what each update is.
  • Each update has a desktop number and a browser number that move together (desktop 1.4.1 comes with browser 3.0.1). Dates are set when an update is nearly ready. If one isn't ready or hasn't been tested properly, it moves instead of shipping, and this page says so.
  • The browser version (the website) updates as soon as the new version is put online, and shows a bar when a newer version is ready. The browser zip is attached to every release.
  • Windows and Linux can update by themselves (version 1.3.2 and newer). In Control Panel you choose: install automatically, ask me first, or just tell me. On a Mac the app tells you when an update is out and links to the download, because Apple's signing isn't paid for yet.
  • Windows is tested on a real PC. Linux can only be tested in a virtual environment.
