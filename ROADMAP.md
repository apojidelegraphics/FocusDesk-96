## How updates work

- Version 1.3.2 (silent updates for Windows and Linux) and version 1.4 (a stability release) are both planned for this week.
- After 1.4, no more updates are planned for now. If a serious problem turns up, especially anything that could lose your data, a fix is still released as quickly as possible.
- If an update isn't ready or hasn't been tested properly, it moves instead of shipping. This page says so and why.
- The browser version (the website) updates as soon as a release is published. The browser zip is attached to every release.
- Windows and Linux get silent updates from version 1.3.2 on. On a Mac the app tells you when an update is out and links to the download, because Apple's signing isn't paid for yet.
- Windows is tested on a real PC. Linux can only be tested in a virtual environment.
